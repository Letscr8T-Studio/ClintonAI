# Clinton AI brand kit

Generated by `npm run brand-kit` from `src/config/logo-mark.json` in the real brand fonts. Don't edit the
images by hand: change the mark or the script, then regenerate. Rules: [docs/product/brand.md](../docs/product/brand.md).

| File                                             | Use                                                                                    |
| ------------------------------------------------ | -------------------------------------------------------------------------------------- |
| `google-oauth-logo-120.png`                      | Google Cloud consent screen logo (120×120, as Google requires)                         |
| `profile-blue-1024.png` / `profile-blue-400.png` | Profile picture: X, LinkedIn, Instagram, YouTube, Product Hunt (safe in a circle crop) |
| `profile-ink-1024.png`                           | Profile picture on a dark background, for variety                                      |
| `app-icon-1024.png`                              | App-store style rounded icon (transparent corners)                                     |
| `mark-blue-1024.png` / `mark-white-1024.png`     | The mark alone, transparent, for light or dark backgrounds                             |
| `logo-on-light.png` / `logo-on-dark.png`         | Mark + "Clinton AI", transparent, for light or dark backgrounds                        |
| `logo-on-paper.png`                              | Mark + "Clinton AI" on the site's paper colour                                         |
| `banner-x-1500x500.png`                          | X (Twitter) header                                                                     |
| `banner-linkedin-1584x396.png`                   | LinkedIn page or profile banner                                                        |

Name in public copy: always "Clinton AI", never "Clinton" alone.
